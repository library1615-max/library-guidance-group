# 全國高級中等學校圖書館輔導團網站

官方網站開發專案 V1。

## 目前功能

- AI × 圖書館 × 藝術風首頁
- 最新消息關鍵字搜尋與分類篩選
- 近期活動卡片
- 中學生網站固定入口
- 高中職小論文檢核輔助系統固定入口
- 專題資源、成果專區、認識輔導團
- 響應式手機版
- 後台登入介面原型

## 重要網站

- 中學生網站：https://www.shs.edu.tw/
- 高中職小論文檢核輔助系統：https://library1615-max.github.io/thesis-format-system/

## 後續規劃

正式後台將加入帳號權限、公告發布、活動管理、圖片與附件上傳、外部網址、操作紀錄，以及資料庫整合。
